# design/mockups

Static mockups. Open any `.html` file in a browser; they load fonts from Google Fonts and share two stylesheets.

| File | Screen |
|---|---|
| [overview.html](overview.html) | Home: invariant statement and pool list |
| [pool.html](pool.html) | Open pool: tier ladder, countdowns, members, live feed |
| [receipt.html](receipt.html) | Settled pool: the settlement receipt |
| [spawn.html](spawn.html) | "Spawn your agent" form and result |
| [how.html](how.html) | "How it works" with a worked example |
| [kit.html](kit.html) | Component kit: every component and state on one page |
| [tokens.css](tokens.css) | Design tokens (colour, type, space) |
| [components.css](components.css) | Component styles used by every mockup |
| [icons.svg](icons.svg) | Icon sprite |

- To find the written spec behind each screen visit [../DESIGN.md](../DESIGN.md) (section 8).
- The production versions of these screens can be found in [../../web/src/routes/](../../web/src/routes/README.md).
